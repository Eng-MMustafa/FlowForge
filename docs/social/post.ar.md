بقيت أكتب للـAI جملة واحدة… ويرجعلي شغل مراجَع ومتختبَر.

المشكلة مش إن الـAI مش بيعرف يكتب كود. المشكلة إنه بيكتبه **من غير خطة، من غير مراجعة، ومن غير ما حد يقول له "قف"**.

عشان كده بنيت **FlowForge**: بدل وكيل واحد يعمل كل حاجة، التاسك بيعدّي على ستة وكلاء متخصصين بالترتيب —

تفكير ← تحليل ← كود ← اختبار ← تصحيح ← رفع

وكل واحد بيسلّم اللي بعده **ملف تسليم مركّز** (خطة، تحليل، ملاحظات كود، مراجعة). ومفيش رفع غير لما المراجع يكتب **PASS** صراحة. والبوابات دي إنت اللي بتقرّرها: توافق من الشاشة، أو من الترمنال، أو تسيبه يكمّل لوحده.

وفيه شاشة تحكم بتشوف فيها كل خطوة لايف: المرحلة اللي شغالة، الموديل المستخدم، الملفات اللي بتتغيّر، والـdiff.

عايز تغيّر الترتيب؟ **ارسمه بالسحب** — تحط الخطوات على كانفس، توصّل الخطوة اللي بعدها ومسار الفشل، وتثبّت لكل مرحلة الموديل ومستوى التفكير. والناتج ملف JSON عادي تقدر تقراه وتعدّله بإيدك.

حاجات مهمة بالنسبالي في المشروع ده:

◾ **صفر مكتبات خارجية.** ولا حزمة واحدة. Node المدمج بس — وفيه اختبار بيفشّل البناء لو أي import مش من Node نفسه.
◾ **288 اختبار** بيشتغلوا من غير أي test framework.
◾ **ويندوز وماك ولينكس** — كل فروق الأنظمة في ملف واحد، والاختبارات بتتأكد من التلاتة من أي جهاز.
◾ **واجهة عربي/إنجليزي كاملة** مع RTL، وفيه اختبار بيفشل لو كلمة واحدة ناقصة في أي لغة.
◾ **بياناتك بتفضل عندك.** تسجيل الدخول بيتم في ترمنال حقيقي عند الأداة نفسها — الداشبورد مابيلمسش أي توكن.
◾ **لو حالة مش قادر يقراها، بيقول "غير معروف"** — مابيخمّنش عليك.

التسطيب أمر واحد، من غير npm install ولا إعدادات:

iwr -useb https://raw.githubusercontent.com/Eng-MMustafa/FlowForge/main/get.mjs -o "$env:TEMP\ff.mjs"; node "$env:TEMP\ff.mjs"

وعلى ماك/لينكس:

curl -fsSL https://raw.githubusercontent.com/Eng-MMustafa/FlowForge/main/get.mjs -o /tmp/ff.mjs && node /tmp/ff.mjs

أو من غير تسطيب خالص: npx flowforge-cli
